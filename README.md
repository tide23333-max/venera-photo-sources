# 我的 VeneraNext 写真源

个人维护的 10 个网站解析脚本，适用于 VeneraNext 1.17.0。这里只分发代码，不存储写真图片、账号、Cookie、收藏或阅读历史。

## 第一次添加仓库

源清单地址：

```text
https://raw.githubusercontent.com/tide23333-max/venera-photo-sources/main/index.json
```

1. 先在 Venera 的设置中找到数据备份/导出功能，保存一份本地备份。不要将应用备份上传到本仓库。
2. 打开“漫画源 → 源仓库 → 添加仓库”。名称填“我的写真源”，地址填上面的 JSON 链接。
3. 浏览仓库。已安装的同名源选择“关联仓库”，没有安装的源才选择安装。不要先卸载原源。
4. 回到“已安装”，点击“检查更新”，先更新 4KHD 一项，检查封面、分类、阅读和已有收藏续读。
5. 确认后再逐个更新其他源。更新失败先保留当前版本，不删除账号和阅读数据。
6. 手机重复添加同一地址、关联和更新。手机无需安装 Git 或登录 GitHub。

关联仓库只指定未来更新位置，不立刻替换现有脚本。源 key 和作品/章节 ID 保持不变，但仍需实际检查旧记录。

## 以后如何更新

你向维护助手提出需求 → 助手修改和测试 → 你确认发布 → 助手更新仓库 → 电脑/手机点击检查更新并选择安装。

这不是后台强制升级。GitHub 只提供脚本；原站、图片服务仍需在设备当前网络下可访问。源代码同步也不会同步收藏、历史或账号。

## 常见问题

- 仓库打不开：在同一设备浏览器打开源清单地址，区分 GitHub 网络问题和原站问题。不使用未知镜像、不自动修改代理。
- 没提示更新：检查源是否关联本仓库、同一 key 的版本号是否增大、清单和脚本是否同步。不要卸载重装。
- 新版异常：用仓库外本地备份恢复对应脚本并重新导入。远程修复发布更高版本，降低版本号不会可靠触发更新。
- 数据备份、目录缓存、登录数据不要放入代码仓库。
